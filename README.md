## Daftar latihan
1. `latihan1_biodata.py`: menampilkan biodata mahasiswa dengan f-string
2. `latihan2_persegi_panjang.py`: menghitung luas dan keliling persegi panjang dari input pengguna
3. `latihan3_konversi_suhu.py`: mengonversi suhu Celsius ke Fahrenheit dan Kelvin
4. `latihan4_total_belanja.py`: menghitung subtotal, PPN 11%, dan total belanja

## Cara menjalankan
Pastikan Python 3 sudah terpasang, lalu jalankan dari folder ini:

```bash
python latihan1_biodata.py
python latihan2_persegi_panjang.py
python latihan3_konversi_suhu.py
python latihan4_total_belanja.py
```
